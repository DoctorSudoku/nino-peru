MCP (para asistentes de IA)

Servidor Model Context Protocol remoto: cualquier cliente compatible puede consultar los datos sin descargar nada. Seis herramientas y un catálogo de recursos.

Endpoint:  https://nino-peru-mcp.doctorsudoku.workers.dev/mcp
Transporte: HTTP (JSON-RPC 2.0), sin sesión
claude mcp add --transport http nino-peru \
  https://nino-peru-mcp.doctorsudoku.workers.dev/mcp

Condiciones

  • Frecuencia: los índices de NOAA se actualizan a diario; el ENFEN, cada dos semanas; INDECI, varias veces al día.
  • Los datos de NOAA son de dominio público. Los documentos del ENFEN e INDECI se citan con su fuente y número.
  • Atribución sugerida: Tablero El Niño Perú — datos de NOAA, ENFEN e INDECI.
  • Si un valor no está disponible se devuelve null, nunca un cero.
